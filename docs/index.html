ppt-rs

Pure Rust Create, read, update, and validate PowerPoint 2007+ (.pptx) — Markdown/HTML import, themes, charts, PDF export, MCP tools.

Create a deck in 10 lines

use ppt_rs::prelude::*;
use ppt_rs::pptx;

fn main() -> ppt_rs::Result<()> {
    let bytes = pptx!("Quarterly Update")
        .slide("Welcome", &["Pure Rust PPTX", "Opens without repair"])
        .slide("Metrics", &["Revenue +12%", "Shipped"])
        .build()?;
    std::fs::write("deck.pptx", bytes)?;
    Ok(())
}

Why pure Rust?

  • No Python/Node runtime — embed in Rust services, WASM-friendly core (zip + xml-rs).
  • Production OOXML — ECMA-376 packaging, validate_package_bytes() zero-repair gate.
  • Developer workflows — pptcli md2ppt, html2ppt, optional ppt_mcp for AI assistants.
