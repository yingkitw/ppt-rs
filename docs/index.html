Markdown → PowerPoint in Rust

// Cargo.toml: ppt-rs = { version = "0.2.37", features = ["markdown"] }

let md = std::fs::read_to_string("slides.md")?;
let bytes = ppt_rs::markdown_to_pptx_bytes(&md, "Team Update")?;
std::fs::write("team-update.pptx", bytes)?;

CLI (from the repo): cargo install ppt-rs --features cli then pptcli md2ppt slides.md

Why pure Rust?

  • No Python/Node runtime — embed in Rust services, WASM-friendly core (zip + xml-rs).
  • Production OOXML — ECMA-376 packaging, validate_package_bytes() zero-repair gate.
  • Developer workflows — pptcli md2ppt, html2ppt, optional ppt_mcp for AI assistants.
