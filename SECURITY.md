# Security

**ppt-rs** is maintained at [github.com/yingkitw/ppt-rs](https://github.com/yingkitw/ppt-rs).

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

1. Use [GitHub Security Advisories](https://github.com/yingkitw/ppt-rs/security/advisories/new) (“Report a vulnerability”), or  
2. Open a minimal issue asking for a private contact channel if advisories are unavailable.

Include steps to reproduce, affected versions, and impact. We aim to acknowledge within a few business days.

## Supported versions

Security fixes are applied to the latest release on `main` and published via [GitHub Releases](https://github.com/yingkitw/ppt-rs/releases), crates.io, and PyPI when applicable.
